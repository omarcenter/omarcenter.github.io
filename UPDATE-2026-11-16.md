# Omar Center PS4 update — 2026-11-16

## Changes
- Added exact firmware 14.02 detection and default routing to the existing same-origin Afterglow frame. 14.00 keeps the same route. 14.01, 14.03 and unlisted versions remain blocked; this is not continuous-range support.
- Pinned Afterglow to 587c00a564c4765b78ab413e400a392efdd9a780. Copied upstream afterglow.js, core.js, jb.js, ps4_offsets.js, goldhen.bin, hen.bin and the new patchset-1402.bin without byte edits. Includes the upstream watchdog fix that stops false failure notices after completion.
- Bundled Afterglow GoldHEN is now 2.4b18.14 (298776 bytes). Older default routes retain their existing payloads and behavior. Optional Afterglow routes: 12.00, 12.02, 12.50, 12.52, 13.00, 13.02, 13.04, 13.50, 13.52.
- Updated /offline.appcache to 2026-11-16-v1 and added patchset-1402.bin. Preserved the query-string fallback for jb.html. Regenerated the standalone host manifest using local file hashes.
- Retained the customized Arabic launcher and no timed cache bypass. Launch waits while checking/downloading; pending updates swap and reload first, with a 10-second guard against reload loops. The root portal still asks to load the newly cached version before launch.
- PS5 and the site's branding/artwork are unchanged.

## Validation and limits
`node tests/ps4-routing-cache.cjs` passes 26 default firmware routes, 11 Afterglow routes, eight unsupported/desktop gates, 12 portal cache states and launcher cache lifecycle cases. Static checks verify cached local resources, payload SHA256 provenance, and unchanged older routes. No exploit was executed in testing. Neither activation nor actual browser AppCache behavior has been tested on a physical PS4 by us; upstream reports hardware tests separately.

## Updating a console's saved site
Connect online and open https://omarcenter.github.io/. Wait for the update to finish, then use the button to load the newly cached version. Wait for the offline-ready message before disconnecting. Successful caching is not proof of GoldHEN activation. Test activation and reopening with the network disconnected on the actual console. Do not change console firmware to match the site.
